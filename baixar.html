Como instalar no celular Android

Cinco passos simples — leva menos de um minuto.

  1. Toque no botão Baixar APK acima (ou escaneie o QR code com a câmera).
  2. Aguarde o download terminar — são apenas 5,7 MB.
  3. Abra o arquivo baixado e toque em Instalar.
  4. Se o celular pedir, permita "Instalar apps de fontes desconhecidas" para o navegador.
  5. Pronto! Abra o Visual Evidence e crie seu primeiro relatório fotográfico.

🔒 O arquivo é o mesmo disponibilizado na página principal. Dúvidas? Fale conosco pela seção Contato.
